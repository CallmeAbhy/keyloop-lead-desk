# Keyloop Technical Assessment — Scenario C: Sales Lead Management Tool

An enterprise-grade **Sales Lead & Quote Management Application** built for **Scenario C (Demand Domain)**[cite: 13, 14]. It satisfies all core Keyloop requirements (Lead Inbox, Lead Details View, and Persistent Chronological Activity Logging) while adding enterprise **Configure, Price, Quote (CPQ)** modules: a **Metadata-Driven Collapsible Form Engine**, **Form Master Schema Versioning**, **Webhook Duplicate Consolidation**, **Unassigned Lead Pool Claiming**, and a **Discount Approval Process (DAP)** guardrail.

---

## 🚀 How to Build, Run, and Test

### Prerequisites

- Node.js (v18+ recommended)
- npm

### Installation & Local Development

```bash
npm install
npm run dev
```
